Third-party components in MiniDisc Manager
==========================================

MiniDisc Manager bundles the open-source components below. Their licence texts are in LICENSES\ and inside each package folder.
The author's own code is covered by LICENSE.txt. This is a notice of what is included, not legal advice.

A. GPL-2.0 libraries (run by helper\*.js on the bundled Node)
-------------------------------------------------------------
himd-js 0.2.7              GPL-2.0   Hi-MD library          https://github.com/asivery/himd-js
netmd-js 4.3.0             GPL-2.0   NetMD library          https://github.com/cybercase/netmd-js
netmd-exploits 0.5.11      GPL-2.0   NetMD/Hi-MD firmware patches (used only for the opt-in NH700 download)   https://github.com/asivery/netmd-exploits
netmd-tocmanip 0.1.5       GPL-2.0   NetMD TOC library      https://github.com/asivery/netmd-tocmanip

NOTICE OF CHANGES (GPL-2.0, section 2a): the copy of himd-js 0.2.7 shipped in runtime\node_modules\himd-js is MODIFIED. Changed file:
dist\himd-functions.js, function deleteTracks (and the new function planFreeRegions, marked "PATCH (MiniDisc Manager)" in the file).
Modified 2026-11-05 by Vinny Powell. What changed: when tracks are deleted, the original code also freed the audio block that a
neighbouring track shares with the deleted one (recorders let one track end in the block the next starts in), which damaged the
neighbour's audio. The modified code never frees a block that a track which stays still uses, merges touching regions, and moves the
remaining tracks by the right amount. The source of the whole library, with this change, is in that folder (it is plain JavaScript).
node-mass-storage 0.2.4    GPL-2.0   USB mass storage       https://github.com/asivery/node-mass-storage
nufatfs 0.1.10             GPL-2.0   FAT file system        https://github.com/asivery/nufatfs
Text of the licence: LICENSES\GPL-2.0.txt (also in each package folder under runtime\node_modules).
These libraries are shipped as readable JavaScript in runtime\node_modules (not minified). The complete source of each version
is at the address above; on request the author will provide a copy of the source.

C. Downloaded only when you ask for it (Lyrics > Listen...)
------------------------------------------------------------
whisper.cpp                MIT   speech recogniser program, downloaded from https://github.com/ggml-org/whisper.cpp/releases into your user folder
Whisper "small" model      MIT   OpenAI's Whisper speech model in the ggml format (ggml-small-q5_1.bin), downloaded from https://huggingface.co/ggerganov/whisper.cpp
These are not part of the installer. They run on this PC and no audio is sent anywhere; "Remove the recogniser" in the Listen sheet deletes them.
The online lyrics lookups (LRCLIB, NetEase Cloud Music, lyrics.ovh) are separate third-party services; only a track's artist, title, album and length are sent.

Photographs of recorders
-------------------------
The recorder pictures in ui\recorders\ are freely licensed photographs from Wikimedia Commons (CC BY, CC BY-SA, or public domain), scaled down.
The authors and licences are listed in ui\recorders\CREDITS.txt and under each picture in the program.
The small MZ-NH700 picture is a product image of that recorder; its copyright remains with its owner (see CREDITS.txt).
