USB driver setup for MiniDisc Manager

A one-time step per recorder. It takes about two minutes and needs a free tool called Zadig.

Why is this needed?
MiniDisc Manager talks to the recorder directly over USB. For that, Windows must use a generic driver called WinUSB for your recorder. Windows normally chooses a different driver (or no driver), so the app cannot see the recorder until you switch it. Nothing else on your PC is affected.
What changes when you do this
  • A Hi-MD recorder will stop appearing as a drive letter in File Explorer. That is expected: the app reads it directly.
  • Sony's own programs (SonicStage, Hi-MD Walkman software) will no longer find that recorder until you undo the change (see the end of this page).
  • You do this for each recorder you use, and once more for the second USB mode if you use both Hi-MD and standard discs (see step 8).

Before you start

  • Close MiniDisc Manager, SonicStage and anything else that uses the recorder.
  • Use a USB cable plugged directly into the PC (not a hub if you can avoid it).
  • Download Zadig from its official site: https://zadig.akeo.ie/. It is a single program; it needs no installation. Zadig is a separate free program by the libwdi / Akeo project and is not part of MiniDisc Manager.

Step by step

  1. Put a disc in the recorder and switch it on. For a Hi-MD recorder, any disc will do. A recorder with a standard MiniDisc inside shows up in a different USB mode (see step 8).
  2. Plug the recorder into the PC with its USB cable. Wait until Windows has finished and the recorder's display shows it is connected.
  3. Run Zadig as administrator. Right-click zadig-2.9.exe and choose Run as administrator. Say Yes to the Windows prompt. If Zadig asks about checking for updates, either answer is fine.
  4. Show all devices. In Zadig's menu choose Options → List All Devices.
  5. Pick your recorder in the drop-down list. It is usually listed as Hi-MD, Net MD or the model name. Check that the two boxes under the list show a Sony ID that matches the table below (the first box is 054C, the second box is the model's ID).
    Be careful: Zadig lists every USB device. Only change the recorder. Replacing the driver of a keyboard, mouse or other device can stop it working.
  6. Choose WinUSB. In the box to the right of the green arrow, use the up/down arrows until it says WinUSB (not libusb-win32, libusbK or WinUSB (v6...) variants).
  7. Click Replace Driver (or Install Driver). Wait for the message "The driver was installed successfully". It can take up to a minute. Then close Zadig.
  8. Standard MiniDiscs too? A Hi-MD recorder uses a different USB ID when it holds a standard (non-Hi-MD) disc. If you want to use standard discs, put a standard disc in the recorder before plugging it in, plug it in, and repeat steps 3 to 7 for that second entry.
  9. Start MiniDisc Manager. The recorder appears in the drop-down at the top right, with a green dot. If it does not, press the rescan button (the circular arrow).

If something does not work

The recorder is not in Zadig's list Make sure Options → List All Devices is ticked. Unplug and re-plug the recorder, wait ten seconds, and press Options → List All Devices twice to refresh. Try another USB port or cable (some cables are charge-only).
The recorder is in Zadig's list, but the app says "No recorder found" Check that the driver shown for the recorder in Zadig (left box) is now WinUSB. Close SonicStage and any other program that uses the recorder. Press the rescan button in the app. A recorder with a standard disc needs its own entry (step 8).
"Access denied" or "could not talk to the recorder" Only one program can use the recorder at a time. Close every other program that uses it (including a second copy of MiniDisc Manager), unplug and re-plug the recorder, and rescan.
The recorder says "PC" or shows no disc, or Windows says the USB device is not recognised Unplug the recorder, remove the disc, put it back, and plug the recorder in again. Wait until its display settles before you start the app.
I want to undo this and get my drive letter back Open Device Manager (right-click the Start button). Under Universal Serial Bus devices find your recorder (it may be named Hi-MD or Net MD), right-click it, choose Uninstall device, tick Attempt to remove the driver for this device, and confirm. Unplug and re-plug the recorder: Windows installs its normal driver again.
Is it safe? Will it harm my recorder or my discs? Switching the driver only changes how Windows talks to the recorder; it does not change the recorder or what is on the disc. Even so, MiniDisc Manager can write to and erase discs. Copy any recordings you cannot replace to your PC (Save to PC...) before you edit a disc, and do not unplug the recorder while the app says it is working.
Check it worked: start MiniDisc Manager. A green dot and your recorder's name appear at the top right, and the disc's tracks are listed.
